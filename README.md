# Репозиторий опытных образцов

Данные проекты были выполнены в ходе различных исследований

| Название проекта | Описание | Используемые библиотеки | 
| :---------------------- | :---------------------- | :---------------------- |
| [Исследование показателей комплекса стенда SWaT](swat_attack_analysis) | Исследование показателей комплекса стенда SWaT, анализ данных показателей стенда в стационарном состоянии и при воздействии атак и создание оптимальной модели предсказания состояния с помощью моделей бинарной классификации | *pandas*, *numpy*, *warnings*, *matplotlib*, *seaborn*, *shap*, *lightgbm*, *sklearn*, *plotly*, *imblearn* |
| [Автоматизация A/B-тестирования для задач анализа выборочных данных](statistical_tests_app) | Проект представляет собой интерактивный инструмент для генерации искусственных выборок данных и их последующего статистического анализа. Пользователь может гибко настраивать параметры генерации (размер выборки, среднее, стандартное отклонение) для симуляции различных сценариев A/B-тестов | *pandas*, *numpy*, *streamlit*, *scipy*, *matplotlib*, *statsmodels* |
| [Автоматизация статистических тестов для задач анализа выборочных данных(прототип)](statistical_tests) | Проект представляет собой комплексный набор функций для генерации данных и проведения статистических тестов различных типов. Реализована возможность работы с нормальными и случайными выборками, а также с зависимыми выборками для анализа парных данных | *pandas*, *numpy*, *scipy*, *matplotlib*, *statsmodels* |
| [Разведывательный анализ(EDA) временных рядов с использованием сингулярного спектрального анализа (SSA)](eda_analysis_app) | Проект предназначен для анализа многомерных временных рядов. Задачей проекта является создание автоматизированного пайплайна для исследования структуры временных рядов | *pandas*, *numpy*, *sklearn*, *scipy*, *statsmodels*, *plotly*, *os*, *sys*, *datetime*, *IPython.display*, *yaml*, *pathlib* |
| [Разведывательный анализ данных (EDA) временных рядов с использованием сингулярного спектрального анализа (SSA)(прототип)](eda_analysis) | Данный проект представляет собой версию анализа временных рядов с применением метода сингулярного спектрального анализа (SSA). Данная тетрадь предназначена для детального исследования структуры многомерных временных рядов с возможностью пошагового выполнения и визуализации результатов | *pandas*, *numpy*,  *matplotlib*, *seaborn*, *scipy*, *statsmodels*, *sklearn* |
| [Анализ корреляции временных лагов с использованием сингулярного спектрального анализа (SSA)](checking_correlation_lag) | Данный проект представляет комплексный анализ временных рядов для определения оптимальных временных лагов между признаками с использованием метода сингулярного спектрального анализа (SSA). Проект реализован в виде Jupyter Notebook для пошагового выполнения анализа и исследования корреляционных зависимостей между временными рядами | *pandas*, *numpy*, *matplotlib*, *seaborn*, *scipy*, *statsmodels* |
