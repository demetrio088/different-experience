# Разведывательный анализ данных (EDA) временных рядов с использованием сингулярного спектрального анализа (SSA)

## Описание

Данный проект представляет собой версию анализа временных рядов с применением метода сингулярного спектрального анализа (SSA). Данная тетрадь предназначена для детального исследования структуры многомерных временных рядов с возможностью пошагового выполнения и визуализации результатов.

## Данные

Notebook работает с CSV-файлом, содержащим временные ряды с несколькими признаками. В рамках анализа исследуются три основных признака:
- `column1` - первый временной ряд
- `column2` - второй временной ряд  
- `column3` - третий временной ряд

Данные должны содержать временную метку в первом столбце, которая автоматически переименовывается в `time_row` и устанавливается как индекс DataFrame.

## Задачи анализа

Notebook решает следующие аналитические задачи:

1. **Первичный разведывательный анализ (EDA)**:
   - Загрузка и предварительный осмотр данных
   - Оценка основной информации датасета, поиск пропусков, дубликатов
   - Построение гистограмм распределений, боксплотов
   - Анализ корреляционных связей между признаками
   - Оценка основных описательных статистик

2. **Сингулярный спектральный анализ (SSA)**:
   - Декомпозиция временных рядов на компоненты
   - Исследование различных параметров окна L (3, 6, 12)
   - Выделение основных компонентов (тренд) и остаточных (шум)

3. **Статистический анализ компонентов**:
   - Проверка на стационарность (тест Дики-Фуллера)
   - Проведение автокорреляционного анализа (ACF/PACF)
   - Проведение частотного преобразования Фурье (FFT)
   - Проверка характера распределения, гомогенности дисперсии
   - Анализ трендов
   - Оценка взаимосвязи компонентов признаков

4. **Верификация результатов SSA**:
   - Реконструкция исходных сигналов из компонентов
   - Оценка качества реконструкции метриками MAE, MSE, RMSE, R²

## Используемые библиотеки

- **pandas** работа с данными в формате DataFrame
- **numpy** для математических вычислений
- **matplotlib.pyplot** визуализация графиков
- **seaborn** расширенная статистическая визуализация
- **scipy.stats** статистические тесты и функции
- **scipy.fft** преобразование Фурье
- **statsmodels** для анализа ACF/PACF и стационарности, расчета стат показателей
- **sklearn.metrics** для расчета метрик качества моделей

## Как использовать Notebook

1. **Подготовка данных**:
   - Сохраните временные ряды в CSV-файл
   - Убедитесь, что временная метка находится в первом столбце
   - Разместите файл по пути, указанному в notebook

2. **Настройка пути к данным**:
   ```python
   df = pd.read_csv('путь_к_вашему_файлу.csv')
   ```

3. **Пошаговое выполнение**:
   - Запускайте ячейки последовательно (Shift+Enter)
   - Анализируйте выводимые результаты и графики
   - При необходимости изменяйте параметры анализа

4. **Интерпретация результатов**:
   - Изучите корреляционные связи между признаками
   - Проанализируйте качество декомпозиции SSA
   - Оцените статистическую значимость выявленных трендов
   - Исследуйте частотные характеристики основных и остаточных компонентов
