# Анализ корреляции временных лагов с использованием сингулярного спектрального анализа (SSA)

## Описание

Данный проект представляет комплексный анализ временных рядов для определения оптимальных временных лагов между признаками с использованием метода сингулярного спектрального анализа (SSA). Проект реализован в виде Jupyter Notebook для пошагового выполнения анализа и исследования корреляционных зависимостей между временными рядами.

## Постановка задачи

Исследование направлено на решение следующих задач:

1. **Анализ обезличенного временного ряда** с тремя признаками
2. **Определение наилучшего временного лага** для каждого левого признака
3. **Исследование свойства процесса**: leftname1 - leftname2 = rightname
4. **Оптимизация корреляции** между разностью левых признаков и правым признаком

## Данные

Notebook работает с CSV-файлом временных рядов, содержащим следующие признаки:
- `datetime` - временная метка (устанавливается как индекс)
- `leftname1` - первый левый временной ряд
- `leftname2` - второй левый временной ряд  
- `rightname` - правый временной ряд (целевой признак)

Данные проходят предварительную обработку с проверкой на пропуски, дубликаты и конвертацией временных меток.

## Задачи анализа

### 1. Первичный разведывательный анализ (EDA)
- Загрузка и предварительный осмотр данных
- Оценка основной информации датасета, поиск пропусков и дубликатов
- Построение гистограмм распределений и боксплотов
- Анализ корреляционных связей между признаками (нулевой лаг)
- Оценка описательных статистик

### 2. Сингулярный спектральный анализ (SSA)
- Декомпозиция временных рядов на основные и остаточные компоненты
- Исследование параметра окна L=3 для минимальных временных интервалов
- Выделение трендовых компонентов (F0) из каждого признака
- Построение матриц взвешенной корреляции между компонентами

### 3. Анализ трендов и статистическая проверка
- Определение трендов методом линейной регрессии
- Оценка статистической значимости наклона (p-value < 0.05)
- Расчет параметров тренда (угол наклона, точка пересечения, R²)
- Проведение автокорреляционного анализа (ACF/PACF)

### 4. Исследование временных лагов
- Анализ корреляции при смещении первого левого признака (0-30 лагов)
- Анализ корреляции при смещении второго левого признака (0-30 лагов)
- Анализ корреляции при смещении правого признака (0-30 лагов)
- Построение графиков динамики коэффициентов корреляции

## Используемые библиотеки

- **pandas** работа с данными и временными рядами
- **numpy** математические вычисления и массивы
- **matplotlib.pyplot** визуализация
- **seaborn** статистическая визуализация/тепловые карты
- **scipy.stats** статистические функции и тесты
- **scipy.fft** преобразование Фурье
- **statsmodels** - анализ временных рядов (ACF/PACF, тест Дики-Фуллера)

## Интерпретация результатов
- **Базовая корреляция**: неочищенных данных составляет ~0.41
- **SSA-корреляция**: между трендовыми компонентами достигает 0.65-0.67
- **Лаговый анализ**: показывает линейное снижение корреляции с ростом лага
- **Оптимальный лаг**: определяется как точка максимальной корреляции

## Основные результаты

### Корреляционный анализ основных компонентов признаков
- Корреляция leftname1 с rightname: 0.65 (сильная прямая)
- Корреляция leftname2 с rightname: -0.29 (слабая обратная)
- Корреляция (leftname1 - leftname2) с rightname: 0.67 (сильная прямая)

### Трендовый анализ
- Все три признака демонстрируют статистически значимые тренды (p < 0.05)
- SSA успешно выделяет трендовые компоненты от шумовых
- Линейная регрессия подтверждает наличие трендов

### Лаговый анализ
- При увеличении лага корреляция снижается линейно
- Максимальная корреляция достигается при нулевом лаге
- Смещение признаков показывает устойчивость корреляционной структуры

## Выводы и рекомендации

1. **Метод SSA эффективен** для выделения трендовых компонентов из временных рядов
2. **Оптимальный лаг равен 0** для данного набора данных
3. **Корреляция между разностью левых признаков и правым признаком максимальна** без временного сдвига
4. **Линейная зависимость снижения корреляции** может использоваться для прогнозирования
