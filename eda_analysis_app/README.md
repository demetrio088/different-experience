# Разведывательный анализ(EDA) временных рядов с использованием сингулярного спектрального анализа (SSA)

## Данные
Проект предназначен для анализа многомерных временных рядов. На вход принимается CSV-файл, содержащий несколько признаков (столбцов) с временными данными, индексируемый по временной метке. В рамках примера анализируются три признака: `column1`, `column2` и `column3`.

## Задача
Задачей проекта является создание автоматизированного пайплайна для исследования структуры временных рядов, который позволяет:
1.  Провести первичный разведочный анализ данных (EDA): загрузка, оценка основных статистик, визуализация распределений, трендов и корреляций.
2.  Выполнить декомпозицию каждого признака на составляющие компоненты (тренд, шум, периодические компоненты) с помощью алгоритма SSA.
3.  Провести детальное исследование полученных компонентов (как основных, так и остаточных) на предмет стационарности, автокорреляции, нормальности распределения и наличия трендов.
4.  Оценить взаимосвязь и сходство между компонентами различных исходных признаков.
5.  Верифицировать качество работы SSA через проверку реконструкции исходного сигнала.

## Результаты проекта
Был разработан модульный скрипт на Python, который автоматизирует процесс анализа временных рядов:
1.  **Первичная обработка и EDA:** автоматическая загрузка данных, переименование столбцов, установка индекса. Для каждого признака строятся графики, гистограммы, boxplot'ы и матрица корреляций. Рассчитываются ключевые описательные статистики.
2.  **Сингулярный спектральный анализ:** каждый признак декомпозируется на компоненты (F0 - основной компонент, F1 - остаточный) заданной `L`.
3.  **Исследование компонентов:** для каждого компонента проводятся статистические тесты и визуальные проверки, включая:
    *   Тест Дики-Фуллера на стационарность.
    *   Анализ автокорреляции (ACF) и частичной автокорреляции (PACF).
    *   Частотный анализ с помощью преобразования Фурье.
    *   Тест Шапиро-Уилка на нормальность распределения.
    *   Анализ трендов с помощью скользящего среднего и линейной регрессии.
    *   Сравнение дисперсий компонентов разных признаков с помощью теста Левена.
    *   Оценка взаимной корреляции между основными компонентами и между остаточными компонентами.
4.  **Верификация SSA:** проводится реконструкция исходного сигнала из компонентов для проверки корректности работы алгоритма.
5.  **Исследование трендов:** для каждого основного компонента проводятся статистические тесты и визуальные проверки, включая:
    *   Анализ трендов с помощью скользящего среднего и линейной регрессии.
    *   Тест Дики-Фуллера на стационарность.
    *   Анализ автокорреляции (ACF) и частичной автокорреляции (PACF). 
    *   Частотный анализ с помощью преобразования Фурье.
    *   Разложение временного ряда компонента на тренд, сезонность, остаток.
    *   Выявление стационарности остатков ряда данных тестом Дики-Фуллера.
    *   Тест на гетероскедаcтичность остатков компонента признака тестом Бройша-Пагана.
    *   Построение модели линейной регрессии -  вычисление статистик тренда основного компонента признака.

## Описание функций
Проект построен по модульному принципу. Основная логика находится в `main.py`, которая использует следующие модули:
*   `src/ssa_analysis.py`: содержит реализацию алгоритма SSA (внешняя библиотека c адаптацией реализации).
*   `src/ssa_checking_reconstruction.py`: содержит функцию для проверки и визуализации реконструкции сигнала.
*   `src/utils.py`: содержит вспомогательный класс для загрузки, сохранения файлов и для первичного анализа данных (поиск пропусков, дубликатов).
*   `src/visualization_data.py`: содержит класс для построения графиков, гистограмм, boxplot'ов и матриц корреляций, который реализован с сохранением данных в папку data.
*   `src/calculation_metrics.py`: содержит класс для проверки метрик для оценки реконструкций.
*   `src/calculation_indicators.py`: содержит класс для расчета описательных статистик.
*   `src/data_reconstruction_research.py`: содержит функцию для проведения исследования реконструкций признаков в диапазонах: 
    - F0 - тренд,
    - F1, F2 - основные парные компоненты цикличности,
    - F3, F4 - дополнительные парные компоненты цикличености,
    - F5, F6 - цикличность более высокого масштаба,
    - F7, F*** - вероятно, шум и случайные колебания.
*   `src/research_components_of_signs.py`: содержит класс для проведения статистических тестов и анализа компонентов.
*   `src/research_signs_pipeline.py`: содержит функцию-пайплайн для исследования признаков с разными параметрами SSA.
*   `src/research_trend.py`: содержит функцию-пайплайн для исследования тренда основных компонентов признаков с разными заданными.
*   `config/parameters.yml`: содержит параметры для работы приложения.

## Логика работы основного скрипта (main.py):
1.  Настраиваются опции отображения DataFrame в консоли и подавляются маловажные предупреждения.
2.  **ШАГ 0:** Данные загружаются из CSV-файла. Проводится первичный обзор, переименование столбца и установка временного индекса. Выполняется полный комплекс визуализации и вывод статистик.
3.  **ШАГ 1:** Исследуются исходные признаки (`column1`, `column2`, `column3`) с помощью SSA с различными длинами окна (`L=3`, `L=6`, `L=12`).
4.  **ШАГ 2:** Каждый признак декомпозируется на два компонента (F0, F1) с помощью SSA с фиксированным окном `L=2`.
5.  **ШАГ 3:** Проводится детальное исследование основных (F0) и остаточных (F1) компонентов каждого признака с помощью набора статистических методов.
6.  **ШАГ 3.1:** Исследуются основные компоненты (F0), проводится их сравнительный анализ и оценка корреляции.
7.  **ШАГ 3.2:** Исследуются остаточные компоненты (F1), проводится их сравнительный анализ и оценка корреляции.
8.  **ШАГ 4:** Выполняется проверка работы алгоритма SSA и реконструкция исходных сигналов из компонентов.

## Логика работы скрипта анализа тренда (trend.py):
1.  Настраиваются опции отображения данных в файл *.txt и подавляются маловажные предупреждения.
2.  **ШАГ 0:** Данные загружаются из CSV-файла. Проводится переименование столбца и установка временного индекса.
3.  **ШАГ 1:** Запускается функция по декомпозиции признаков (`column1`, `column2`, `column3`) с помощью SSA с заданной длиной окна (например, `L=2`).
4.  **ШАГ 2:** Каждый признак декомпозируется на два компонента (F0, F1) с помощью SSA с фиксированным окном `L=2`.
5.  **ШАГ 3:** Компоненты признаков группируются в основные и остаточные(шум) и сохраняются в папку `trend_research` в формате *.csv.
6.  **ШАГ 4:** Проводится детальное исследование основного (F0) компонента каждого признака с помощью набора статистических методов.

## Установка и запуск
1.  Убедитесь, что у вас установлен Python(версия 3.11.7) и необходимые библиотеки (список выше). Установите их с помощью `pip`
2.  Скопируйте папку с проектом, включая папку `src` и модули.
3.  Уточните параметры конфигурации в файле parameters.yml
4.  Запустите основной или вспомогательный скрипты: python main.py, python trend.py

## Как использовать
1.  Подготовьте ваши данные в формате CSV. Временная метка должна быть в первом столбце (он будет переименован в `time_row` и установлен как индекс). Признаки должны быть расположены в последующих столбцах.
2.  Уточните параметры конфигурации в файле parameters.yml.
3.  Запустите скрипт. Анализ будет выполнен полностью автоматически и последовательно выведет в консоль (или отобразит в IDE), сохранит визуализации в папку `data`, либо в `trend_research`(в зависимости от того, какой вид анализа выбран(полное исследование, либо исследование тренда)):
    *   Первичную информацию о данных и таблицы со статистиками.
    *   Множество графиков для визуального анализа.
    *   Результаты всех статистических тестов для компонентов.
    *   Графики реконструкции для верификации SSA.
    *   Для анализа тренда - log-файл в формате *.txt/

Проект представляет собой готовый инструмент для глубокого исследования структуры временных рядов, выявления их скрытых компонентов и статистической оценки их свойств.
