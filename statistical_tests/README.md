# Автоматизация статистических тестов для задач анализа выборочных данных

## Данные
Проект представляет собой комплексный набор функций для генерации данных и проведения статистических тестов различных типов. Реализована возможность работы с нормальными и случайными выборками, а также с зависимыми выборками для анализа парных данных.

## Задача  
В рамках задачи проекта предстояло реализовать модульные функции для:
- генерации различных типов выборок (нормальные, случайные, зависимые),
- визуальной и статистической проверки нормальности распределения,
- автоматического выбора подходящего статистического критерия,
- проведения параметрических и непараметрических тестов,
- интерпретации результатов с подробным выводом статистик.

## Результаты проекта
Создана библиотека функций, которая автоматизирует весь цикл статистического анализа:
1. Генерация данных: функции `generate_random_normal()`, `generate_random()`, `generate_dependent_samples()` для создания различных типов синтетических выборок,
2. Визуальная диагностика: построение гистограмм и Q-Q plots для оценки нормальности распределения,
3. Статистическая проверка: расчет описательных статистик (среднее, медиана, дисперсия, стандартное отклонение, стандартная ошибка), проверка нормальности с помощью критерия Шапиро-Уилка и однородности дисперсий с помощью теста Левена,
4. Параметрические тесты: одновыборочный и двухвыборочный t-тест, однофакторный ANOVA с пост анализом Тьюки,
5. Непараметрические тесты: тест Манна-Уитни, критерий Колмогорова-Смирнова, критерий Вилкоксона,
6. Автоматические пайплайны: `pipeline_all_params()` и `pipeline_all_noparams()` для полного цикла анализа.

## Описание функций
Тетрадка построена по модульному принципу с четким разделением функций по назначению:

### Функции генерации синтетических данных:
- `generate_random_normal(sample_size, mean, std)`: генерация нормально распределенной выборки
- `generate_random(sample_size, max_value)`: генерация случайной выборки
- `generate_dependent_samples(scale_difference, sample_size)`: генерация зависимых выборок для парного анализа

### Функции визуализации:
- `hist_sample(data, title)`: построение гистограммы выборки
- `qq_plot_sample(data, title)`: построение Q-Q plot для проверки нормальности

### Функции статистической проверки:
- `shapiro_uilk(title, sample, alpha)`: тест Шапиро-Уилка на нормальность
- `sample_stats(sample)`: расчет описательных статистик
- `test_leven(*samples, alpha)`: тест Левена на гомогенность дисперсий

### Параметрические тесты:
- `student_test_one_sample(sample, sample_mean, test_type, alpha)`: одновыборочный t-тест
- `student_test_two_samples(sample_1, sample_2, test_type, equal_var, alpha)`: двухвыборочный t-тест
- `anova_one(*samples, alpha)`: однофакторный дисперсионный анализ
- `post_analysis_anova_tukey(*samples, alpha)`: пост анализ Тьюки

### Непараметрические тесты:
- `mann_uitni(sample_1, sample_2, test_type, alpha)`: U-критерий Манна-Уитни
- `wilcoxon(sample_1, sample_2, test_type, alpha)`: критерий Вилкоксона для двух зависимых выборок
- `kolmogorov_smirnov(sample_1, sample_2, test_type, alpha)`: двухвыборочный критерий Колмогорова-Смирнова

### Автоматические пайплайны:
- `pipeline_all_params(samples, names, indicator, alpha=0.05, type_test='', subtype_test='', equal_var=True)`: полный анализ для параметрических данных
- `pipeline_all_noparams(samples, names, indicator, alpha=0.05, type_test='', subtype_test='')`: полный анализ для непараметрических данных

## Логика работы основных функций:
1. Генерируются выборки с заданными параметрами,
2. Строятся гистограммы и Q-Q plots для визуальной оценки,
3. Рассчитываются описательные статистики,
4. Проводится тест Шапиро-Уилка на нормальность,
5. В зависимости от результатов выбирается параметрический или непараметрический подход,
6. При необходимости проводится тест Левена на однородность дисперсий,
7. Выполняется соответствующий статистический тест,
8. Результаты интерпретируются и выводятся с указанием статистики, p-value и заключения по гипотезе.

## Используемые библиотеки и технологии
- numpy==1.26.4 (генерация данных и математические вычисления)
- pandas==2.1.4 (работа с данными в виде DataFrame)
- scipy==1.11.4 (статистические тесты и методы)
- matplotlib==3.8.0 (построение графиков)
- statsmodels==0.14.0 (расширенные статистические методы, включая пост-хок тесты)

## Как использовать
1. Загрузите все необходимые библиотеки из первого блока кода,
2. Определите тип анализа и сгенерируйте данные с помощью соответствующих функций,
3. Используйте функции пайплайна для автоматического анализа или вызывайте отдельные функции по необходимости,
4. Задайте уровень значимости(по умолчанию 0.05),
5. Интерпретируйте результаты на основе выведенной статистики и p-value,
6. При необходимости проведите дополнительные тесты или измените параметры анализа.

Проект позволяет комплексно подходить к статистическому анализу данных, автоматически выбирать подходящие методы и получать интерпретируемые результаты для принятия статистических решений.
