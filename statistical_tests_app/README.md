# Автоматизация A/B-тестирования для задач анализа выборочных данных

## Данные
Проект представляет собой интерактивный инструмент для генерации искусственных выборок данных и их последующего статистического анализа. Пользователь может гибко настраивать параметры генерации (размер выборки, среднее, стандартное отклонение) для симуляции различных сценариев A/B-тестов.

## Задача
В рамках задачи проекта предстояло построить модульное веб-приложение, которое позволяет:
- генерировать данные для A/B-тестов,
- визуально и статистически оценивать свойства полученных выборок(нормальность распределения, гомогенность дисперсий),
- автоматически выбирать и применять корректный статистический критерий для сравнения групп на основе свойств данных,
- интерпретировать результаты тестов и предоставлять понятное заключение о наличии или отсутствии статистически значимых различий.

## Результаты проекта
Было разработано веб-приложение на базе Streamlit. Приложение автоматизирует ключевые этапы анализа A/B-тестов:
1. Генерация данных: реализована возможность создания случайных нормальных и произвольных выборок, а также зависимых выборок для симуляции "до и после",
2. Визуальная проверка: для каждой выборки автоматически строятся гистограммы и Q-Q plot для оценки нормальности распределения,
3. Статистическая проверка: рассчитываются основные описательные статистики(среднее, медиана, дисперсия, стандартное отклонение, стандартная ошибка). Проводится формальная проверка на нормальность с помощью критерия Шапиро-Уилка и на однородность дисперсий с помощью теста Левена,
4. Автоматический выбор теста: система выбирает подходящий статистический критерий на основе свойств данных(параметрический или непараметрический, для независимых или зависимых выборок),
5. Проведение теста и интерпретация: запускается выбранный тест(t-тест Стьюдента, ANOVA, Манна-Уитни, Колмогорова-Смирнова, Вилкоксона) и предоставляется подробная интерпретация результата(p-value, размер статистики и заключение относительно нулевой гипотезы).

## Описание функций
Приложение построено по модульному принципу. Основная логика находится в app.py, которая использует следующие модули:
- src/parametric_tests_streamlit.py: содержит класс ParametricTest для проведения параметрических тестов(t-тест, ANOVA),
- src/nonparametric_tests_streamlit.py: содержит класс NonparametricTest для проведения непараметрических тестов(Манна-Уитни, Колмогорова-Смирнова, Вилкоксона),
- src/utils/visual_checking_streamlit.py: содержит класс VizualAnalyzerParams для визуальной проверки данных(построение гистограмм и Q-Q plots),
- src/criterion_checking_streamlit.py: содержит класс CriterionCheck для статистической проверки критериев(Шапиро-Уилка, Левена, пост-хок теста Тьюки),
- src/utils/statistics_calc.py: содержит класс StatisticsCalc для расчета базовых описательных статистик,
- src/utils/generators.py: содержит функции(generate_random_normal, generate_random, generate_dependent_samples) для генерации различных типов выборок.

## Логика работы основного приложения (app.py):
1. Настраивается внешний вид страницы и инициализируются переменные сессии,
2. В боковой панели пользователь выбирает тип эксперимента и задает параметры для генерации данных,
3. При нажатии на кнопку данные генерируются и сохраняются в st.session_state,
4. Пользователь запускает проверку данных на нормальность,
5. Приложение отображает сгенерированные данные, графики и статистики,
6. На основе результатов проверки боковая панель предлагает доступные статистические тесты,
7. После выбора и запуска теста результаты и их интерпретация выводятся в основном интерфейсе.

## Используемые библиотеки и технологии
- streamlit==1.30.0 (веб-фреймворк для создания интерфейса)
- pandas==2.1.4 (работа с данными в виде DataFrame)
- numpy==1.26.4 (математические вычисления и работа с массивами)
- scipy==1.11.4 (статистические тесты и методы)
- matplotlib==3.8.0 (построение графиков)
- statsmodels==0.14.0 (расширенные статистические методы, включая пост-хок тесты)
- python==3.11.7

## Установка и запуск
1. Скопируйте папку с проектом,
2. Установите необходимые зависимости из файла requirements.txt:
pip install -r requirements.txt
3. Запустите Streamlit-приложение:
streamlit run app.py / python -m streamlit run app.py
4. Приложение автоматически откроется в вашем браузере по адресу http://localhost:8501.

## Как использовать
1. В боковой панели выберите тип входных данных(например, "Две случайные нормальные выборки"),
2. Задайте параметры для генерации данных(размер выборки, среднее, стандартное отклонение),
3. Нажмите кнопку "Сгенерировать данные",
4. Задайте уровень значимости(по умолчанию 0.05) и нажмите "Проверить распределение на нормальность",
5. Изучите полученные графики и статистики,
6. В боковой панели выберите тип и название теста, который стал доступен после проверки, и нажмите "Запустить тест",
7. В главной области приложения появится подробный отчет с результатами выбранного статистического теста и его интерпретацией.
8. Для перехода и выбора другого теста обновите страницу для очистки кэша.

Проект позволяет наглядно экспериментировать с данными, понимать условия применимости различных статистических критериев и корректно интерпретировать результаты A/B-тестирования.
